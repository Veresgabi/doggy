# Create Pull Request

## Purpose

Create a GitHub Pull Request for completed changes.

## Steps

1. Check the current git status.

2. Review all changed files.

3. Ensure tests pass.

4. Create a meaningful commit message.

5. Prepare Pull Request information.

## Pull Request format

Title:

<short description of change>

Description:

## Summary
- Describe implemented functionality.

## Changes
- List modified components.

## Testing
- Describe executed tests.

## Technical Notes
- Mention important design decisions.

## Instructions

Use GitHub MCP tools when available.

Create:
- branch if needed
- commit
- pull request

Do not merge the pull request.
