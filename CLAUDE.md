# Project

Spring Boot REST application.

## Coding standards

- Use Java 21.
- Use constructor injection.
- Follow existing package structure.
- Keep methods short.
- Do not introduce new libraries unless requested.
- Write JUnit 5 tests for new code.
- Prefer immutable DTOs.
- Use meaningful commit messages.

## Build

./mvnw clean test

## Pull Requests

- Keep PRs focused.
- Include a summary.
- Mention related GitHub issue.
